# Portfólio — Gabriel Paz

Site estático feito com HTML, CSS e JavaScript.

## Abrir localmente
Abra o arquivo `index.html` no navegador.

## Publicar no GitHub Pages
Suba o conteúdo desta pasta para um repositório GitHub público e ative **Settings → Pages → Deploy from a branch → main → /(root)**.

## Conteúdo
- `index.html`: seções início, sobre, projetos, trajetória e contato.
- `assets/css/style.css`: layout responsivo e estilos.
- `assets/js/main.js`: menu móvel e ano automático no rodapé.
- `assets/img/gabriel.jpg`: avatar público do GitHub; `assets/img/copa14/`: imagens do projeto recebido.

Os links de projetos direcionam aos repositórios públicos de SaintGabs.
